# DataCo Supply Chain Analysis

An end-to-end data analytics project focused on exploring supply chain operations, sales performance, customer behaviour, and delivery efficiency using the DataCo Smart Supply Chain dataset.

## Project Overview

This project aims to analyze supply chain data to identify business trends, evaluate operational performance, and generate meaningful insights that can support data-driven decision-making.

The analysis will focus on sales and profitability, customer segments, product performance, shipping patterns, and delivery performance.

## Objectives

- Analyze overall sales and profit performance.
- Identify top-performing products and categories.
- Understand customer purchasing patterns and segments.
- Evaluate shipping methods and delivery performance.
- Identify trends and patterns across markets and regions.
- Perform basic data quality checks to improve data reliability.

## Dataset

**Dataset:** DataCo Smart Supply Chain for Big Data Analysis

**Source:** [Kaggle – DataCo Smart Supply Chain Dataset](https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis)

The dataset contains approximately 180,519 records and 53 columns, covering order transactions, customer information, product details, sales, and shipping performance.

## Tools & Technologies

- **Python:** Data cleaning, analysis, and visualization
- **Pandas & NumPy:** Data manipulation and preprocessing
- **Matplotlib & Seaborn:** Exploratory data visualization
- **SQL / MySQL:** Data querying and business analysis
- **Tableau:** Interactive dashboards and reporting
- **Git & GitHub:** Project version control

## Project Workflow

1. **Data Collection:** Obtain and understand the dataset.
2. **Data Cleaning:** Handle missing values, duplicates, and inconsistent data.
3. **Exploratory Data Analysis:** Explore trends, patterns, and relationships.
4. **SQL Analysis:** Answer business questions using SQL queries.
5. **Data Visualization:** Build dashboards to communicate findings.
6. **Data Quality Validation:** Perform basic checks on data types, missing values, duplicates, and calculated metrics.
7. **Business Insights:** Summarize findings and suggest improvements.

## Key Business Questions

- Which product categories generate the highest sales?
- Which customer segments contribute the most revenue?
- Which markets perform best in terms of sales and profit?
- Which shipping modes have higher delivery delays?
- How does sales performance change over time?
- What factors are associated with late deliveries?

## Data Quality & Validation

Basic testing will be included to ensure the reliability of the analysis:

- Check for missing and duplicate records.
- Validate column data types.
- Verify calculated sales and profit metrics.
- Cross-check selected results between Python and SQL.
- Identify inconsistent or invalid values.
